# Personal Mac profile review

These decisions are recorded in `outfit.yaml`. No settings have been applied to
the current workstation. See the README for the independent app lists and
remaining manual steps.

## Profile independence

Everyday and Dev have independent app and configuration lists. Neither inherits
the other. Shared apps must be selected explicitly in both profiles.

## Launch at login

Dev: no launch-at-login apps selected yet.

Installing an app and enabling launch at login are separate choices. Everyday
includes a manual action describing these three startup choices. Login-item
automation is not implemented, and these selections do not change login items
on the current Mac.
